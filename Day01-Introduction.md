A software is set of computer instruction designed to complete a given task.

Software engineering is the science of identifying a problem, gather the requirements necessary for solving it,plan,design a credible 
solution, code, test out the program solution, deploy, mantain and document the flow of the whole process of how the solution has been 
developed and put out to work as a solution to what was the challenge.
Hence the steps or procedures of software development being;-
- Requirements
- Planning
- Designing
- Coding 
- Testing
- Deploy 
- Document 
- Maintainance
